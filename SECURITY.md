# Security Policy

Please do not report suspected vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature on this repository's Security tab if it is available. If it is not available, contact a repository maintainer privately through a contact method they have made available before sharing details.

Include the affected files, a description of the impact, and steps to reproduce. Do not include secrets or personal data. Maintainers will investigate and coordinate disclosure as resources permit. This early-stage project does not currently promise a response deadline or a supported-version schedule.
