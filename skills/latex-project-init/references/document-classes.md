# Document classes

- `article`: short papers, assignments, and scientific articles; sections but no chapters.
- `report`: longer technical or academic reports with chapters.
- `book`: long-form work with chapters and book-style front and back matter; adapt two-sided layout only if needed.
- `beamer`: presentations organized into frames; use a plain default theme unless requested otherwise.
- `letter`: correspondence using `letter` environments, an opening and closing, and optional sender and recipient details. Do not impose article-style section structure.

Infer a class from the request when the purpose is clear. Ask when the intended form remains ambiguous. Explicit journal or institutional requirements take precedence; check compatibility before substituting another class. Templates provide generic beginnings, not compliance with publisher specifications.
