# Getting started

SideLeaf Skills is in early development. The repository includes [latex-project-init](../skills/latex-project-init/), a skill for starting LaTeX projects. The repository includes a local npm installer; see the [installation guide](installation.md).

## Use the skill

Access [SKILL.md](../skills/latex-project-init/SKILL.md) together with its adjacent `references/` and `assets/` directories. Provide the skill to an agent that supports the Agent Skills format using that agent’s documented local-skill mechanism, or ask an agent to read the file and follow its instructions. Tell it the destination and what kind of document you need; it can infer routine defaults and ask when necessary. Agent support differs; the installation guide lists documented project-local paths. A compatible LaTeX distribution is needed to compile the resulting project.

## Contributing

Clone the repository using its GitHub clone URL and open it in your preferred editor. Read [CONTRIBUTING.md](../CONTRIBUTING.md) and the [skill development guide](skill-development.md) before proposing a contribution. Individual skills may have their own environment requirements.
