# Code of Conduct

Help make this project welcoming and constructive. Treat others with respect, accept good-faith feedback, and focus on the work rather than personal attacks. Harassment, discrimination, threats, and the disclosure of others' private information are unacceptable.

Project maintainers may remove inappropriate content or restrict participation when nee. To report a concern, contact the repository maintainers privately through a GitHub contact method they have made available; avoid posting sensitive details in a public issue. Maintainers should handle reports discreetly and fairly.
